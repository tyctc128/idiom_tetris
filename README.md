# 成語方塊（成語俄羅斯方塊）

給國小四年級的成語網頁遊戲，電腦與 iPad 都能玩。

**線上遊玩：** https://tyctc128.github.io/idiom_tetris/

## 玩法

- **成語填充**：上方掉下四條不同形狀的答案磚塊，選出正確的那條，移動、旋轉後放到底部（形狀不能改）。
- **看解釋湊成語**：依順序點四個字放進組字盤，選形狀、旋轉後放到底部。
- 答對：其他磚塊爆破，答對的磚塊留在底部；答錯：所有磚塊亂竄，以隨機方向和位置亂堆下來（會留下空洞）。
- 排滿一整排會閃光消除；每 8 題一關，共 5 關 40 題，越後面越快，過關時磚塊會保留。
- **寶箱**：每過兩關得到一個寶箱，遊戲中點寶箱（或按 `B`），堆積的磚塊會全部閃光消失。
- 每局題目順序、選項和干擾字都會重新隨機。

## 操作

- 電腦：`←` `→` 移動、`↑` 旋轉、`↓` 加速、空白鍵直接落下、`Tab`／`1~4` 換選項、`C` 換形狀、`P` 暫停
- iPad：點磚塊選擇、左右滑動移動、點一下旋轉、快速往下滑直接落下，也可用畫面兩側按鈕

## 檔案

- `index.html`：遊戲本體（題庫已內建，單一檔案即可執行）
- `questions.json`：題庫原始資料（改題目時，`index.html` 裡的題庫要一起改）
- `style-preview.html`：視覺風格與音效預覽頁

## 本機執行

```bash
python -m http.server 8123 --bind 0.0.0.0
```

再用瀏覽器開 `http://localhost:8123`，同一個 Wi-Fi 的 iPad 用電腦的區網 IP 開啟。
