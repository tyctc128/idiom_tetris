# 成語方塊（成語俄羅斯方塊）

給國小四年級的成語網頁遊戲，電腦與 iPad 都能玩。

**線上遊玩：** https://tyctc128.github.io/idiom_tetris/

## 玩法

- **成語填充**：上方掉下四條不同形狀的答案磚塊，選出正確的那條，移動、旋轉後放到底部（形狀不能改）。
- **看解釋湊成語**：依順序點四個字放進組字盤，選形狀、旋轉後放到底部。
- 答對：其他磚塊爆破，答對的磚塊留在底部；答錯：所有磚塊亂竄，以隨機方向和位置亂堆下來（會留下空洞）。
- 排滿一整排會閃光消除；每 8 題一關，共 5 關，越後面越快，過關時磚塊會保留。
- **寶箱**：每過兩關得到一個寶箱，遊戲中點寶箱（或按 `B`），堆積的磚塊會全部閃光消失。

## 隨機出題

目前遊戲使用 `question2.json`：課本「成語萬花筒」的 24 個成語（難度 3～5）。題目不是固定的，每一題都是當場產生：

- 每關 8 題，以該關難度為主（題庫沒有的難度會改用最接近的）。
- 題型隨機（每關 3～5 題成語填充，其餘為看解釋湊成語）；填充題隨機挑一句例句，湊成語隨機用「解釋」或「解釋2」。
- 填充題保留 1～3 個課本設計的錯誤選項，其餘從題庫隨機抽，並排除「類別」相同（意思相近）的成語。
- 湊成語的干擾字以課本設計的那組為主，再隨機補到該關數量（3～6 個）。
- 一局 40 題但只有 24 個成語，所以會先把 24 個都出過一輪才重複，重複時會換題型、例句或解釋。
- 瀏覽器會記住最近出過的成語，下一局優先出沒出過的。

## 操作

- 電腦：`←` `→` 移動、`↑` 旋轉、`↓` 加速、空白鍵直接落下、`Tab`／`1~4` 換選項、`C` 換形狀、`P` 暫停
- iPad：點磚塊選擇、左右滑動移動、點一下旋轉、快速往下滑直接落下，也可用畫面兩側按鈕

## 檔案

- `index.html`：遊戲本體（題庫已內建，單一檔案即可執行）
- `question2.json`：**目前使用的題庫**（成語萬花筒 24 個成語：難度、類別、解釋、解釋2、例句、選項、干擾字）
- `questions.json`：另一份 150 個成語的題庫（目前沒有使用）
- `更新題庫.py`：改完題庫後執行 `python 更新題庫.py`，會檢查格式並同步到 `index.html`；要改用其他題庫檔可執行 `python 更新題庫.py questions.json`
- `style-preview.html`：視覺風格與音效預覽頁

## 本機執行

```bash
python -m http.server 8123 --bind 0.0.0.0
```

再用瀏覽器開 `http://localhost:8123`，同一個 Wi-Fi 的 iPad 用電腦的區網 IP 開啟。
